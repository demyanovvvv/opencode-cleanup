# Changelog

Notable changes are recorded here. Package releases use semantic versioning.

## [0.2.1] - 2026-10-11

### Added

- English and Russian README documentation with installation and command references.
- Compatibility, contribution, support, security and release documentation.
- GitHub issue and pull-request templates.
- GitHub Actions checks for Windows and Linux.
- Built-entrypoint TUI smoke coverage with the OpenTUI test renderer.
- Installable release archives and SHA-256 checksums.

### Changed

- Package version advanced from `0.2.0` to `0.2.1`.
- Package metadata now links to the GitHub repository and issue tracker.
- Distributed documentation includes the Russian README and changelog.

This is the first GitHub release. The pre-existing local package was `0.2.0`;
no earlier Git history was available to reconstruct its release notes.
