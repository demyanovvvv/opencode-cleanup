# Support

For bugs and feature requests, use [GitHub Issues](https://github.com/demyanovvvv/opencode-cleanup/issues). Access to the repository is required while it is private.

Before reporting an installation problem, confirm the [runtime requirements](docs/COMPATIBILITY.md), run the installer from the extracted package directory and restart OpenCode. Include:

- Operating system and architecture.
- Node.js, Bun (if relevant), OpenCode and plugin package versions.
- The command or palette action used and the complete error message.
- Expected behavior, observed behavior and reproducible steps.
- A synthetic schema or fixture if the issue concerns SQLite.

Remove private paths, prompts, session content, tokens and provider credentials from logs. Do not upload your real database, backup or history archive. Report vulnerabilities through [SECURITY.md](SECURITY.md).

For development checks, see [CONTRIBUTING.md](CONTRIBUTING.md).
